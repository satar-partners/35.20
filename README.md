# Платформа 32.50 — сайт-визитка

Статический сайт на HTML, CSS и JavaScript. Не требует PHP, Node.js или базы данных для отображения страниц.

## Состав
- `index.html` — главная
- `services.html` — все направления
- `service-prosthetics.html` — протезирование
- `service-rehabilitation.html` — реабилитация
- `service-support.html` — сопровождение
- `technologies.html` — технологии
- `about.html` — о компании
- `patients.html` — информация пациентам и FAQ
- `cases.html` — истории/кейсы (сейчас демонстрационные карточки)
- `contacts.html` — контакты и форма
- `css/style.css` — стили и адаптивность
- `js/main.js` — мобильное меню и демонстрационная обработка формы
- `assets/images/` — отдельные изображения
- `assets/favicon.svg` — иконка сайта
- `robots.txt`, `sitemap.xml` — базовые SEO-файлы

## Проверка локально
Откройте `index.html` в браузере. Для более удобной проверки можно использовать VS Code + расширение Live Server.

## Загрузка на сервер
1. Распакуйте архив.
2. Откройте корневую папку `p3250-website`.
3. Загрузите **содержимое** этой папки в web-root хостинга (часто `public_html`, `www` или `htdocs`) через панель хостинга или SFTP.
4. Убедитесь, что `index.html` лежит прямо в корневой папке сайта, а не во вложенной папке.
5. Подключите домен `p3250.ru` в панели хостинга и включите HTTPS/SSL.
6. Проверьте все страницы и форму после публикации.

## Перед публикацией обязательно заменить/проверить
- Номер телефона, email, адреса, юридические сведения.
- Демонстрационные показатели «15+», «500+», «92%».
- Иллюстративные фото — на лицензированные реальные фотографии изделий/команды или утверждённые фотоматериалы.
- Карточки историй: сейчас это шаблоны, не отзывы реальных пациентов.
- Описание услуг, состав команды, сведения о производителях и сертификации.
- Политику конфиденциальности, согласие на обработку персональных данных и текст согласия у формы.
- Подключение формы к CRM, почте или backend. Текущая форма показывает только демонстрационное сообщение и не отправляет данные.
- Cookie/аналитику и необходимые уведомления, если они будут использоваться.

## Важно
Это готовая статическая заготовка для загрузки на сервер, но перед публикацией нужно внести фактические данные компании, юридические тексты и подключить отправку заявок. Не публикуйте неподтверждённые медицинские заявления, отзывы или статистику.
